# NEON ARCADE 霓虹遊戲場

和朋友一起逛的 Q 版 3D 霓虹遊戲場，整個遊戲就是一個 `index.html`（不需要建置）。

- 1F：保齡球館（4 條球道、計分螢幕與動畫）、復古機台、休息區的大螢幕
- 2F：電玩區、投籃機、夾娃娃機
- 小遊戲：保齡球、貪食蛇、疊疊樂、打地鼠、投籃機
- 多人：用 Supabase Realtime 同步位置、聊天、表情
- 語音：WebRTC 真語音通話（🎧 加入、🎙 開麥克風），說話的人會有綠色光環，名單裡顯示網路與語音延遲
- 一起看 YouTube：📺 貼上連結，所有人同步播放

## 設定

`index.html` 開頭的 config 區：

| 名稱 | 說明 |
| --- | --- |
| `SB_URL` / `SB_KEY` | Supabase 專案網址與 anon 公開金鑰（只用到 Realtime，不會讀寫資料庫） |
| `ROOM` | 頻道名稱，改掉就是另一個獨立的遊戲場 |
| `YT_API_KEY` | 選填。填入 YouTube Data API v3 金鑰後，📺 面板可以直接搜尋影片；沒填時會開 YouTube 搜尋頁，複製連結貼回來即可 |

## 本機測試

在網址後面加 `?local`，同一個瀏覽器開兩個分頁就會互相連線（不經過 Supabase）。

## 限制

- Supabase 免費方案：同時最多 200 人連線、每秒 100 則即時訊息，遊戲會依人數自動降低同步頻率，同一個遊戲場建議 8 人以內。
- 語音是點對點連線（只用 STUN，沒有 TURN 伺服器），少數公司或電信網路可能連不上語音，其他功能不受影響。
