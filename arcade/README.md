# AVÉRA

開在瀏覽器裡的 Q 版 3D 遊戲場。整個網站就是一個 `index.html`（主頁、條款、包廂大廳、遊戲都在裡面），不需要建置。

## 內容

- **網站**：主頁介紹、關於、常見問題、服務條款、隱私權政策、社群守則、聯絡我們（只透過網站表單）。遊玩即代表同意條款。
- **帳號**：第一次進入要填匿名暱稱（必填，2–12 字）並建立角色；角色建立後玩家不能自行更改。暱稱 14 天內最多改 2 次。一個帳號同時只能在一台裝置上遊玩（設定 →「帳號」有轉移碼）。
- **包廂**：建立包廂（名稱、人數上限、公開或私人、密碼、上鎖、燈光主題）、邀請連結、版主可改設定與請人離開；版主離開後包廂倒數 30 秒關閉；閒置 8 分鐘提醒、10 分鐘自動離開；人數滿了自動排隊；官方包廂由管理員建立、永久開放。
- **場館**：黑色大理石地板（極致畫質有即時倒影）、LED 燈條與燈柱、AVÉRA 招牌、照真實樣式做的街機、四線保齡球、點心吧（排隊、店員製作、用代幣購買）、走進去拍照的拍貼機、全館同步的電視與待播清單螢幕。
- **遊戲**：所有機台都在機台本身的螢幕或桌面上玩（鏡頭自動推近，手機上填滿畫面）；夾娃娃是完整 3D；雙人遊戲都能和電腦對戰或真人對戰。
- **點歌**：大家輪流點 YouTube（公平輪替，每人最多排 3 首），點歌的人、版主、管理員可以跳過，其他人可投票跳過。
- **HUD**：統一的通知列（不會重疊）、左上角網路狀態與誰在說話、麥克風講話時的聲波、分頁式設定（每個人的音量、道具、帳號、回報問題）、第一次進入的新手教學。
- **後台**：玩家搜尋與處分（踢出、禁言、停權）、改名、改角色、發特殊道具與代幣、權限、包廂管理、回報處理、即時公告、進場公告、燈光主題、人數上限、維護模式、點心吧菜單、電視控制、操作紀錄。

## 後端

- **正式網站**：Supabase。請到 Supabase 專案的 SQL Editor 執行 `supabase/avera.sql`。所有資料放在獨立的 `avera` schema，只透過 `public.avera_*` 函式存取，規則都在伺服器端檢查；不會動到同一個專案裡的其他資料表。
- **站長**：網站上進入遊戲後，設定 →「帳號」→「輸入站長金鑰」。金鑰另外提供，不在這個 repo 裡。
- **claude.ai 預覽**：使用預覽頁內建的資料庫與身分（版主／編輯者即為管理員）。

## 原始碼

`src/` 是拆開的原始碼，`src/build.sh` 依序串成 `index.html`。
