# NEON ARCADE 霓虹遊戲場

和朋友一起逛的 Q 版動物 3D 霓虹遊戲場。整個遊戲就是一個 `index.html`，不需要建置。

## 內容

- **介面**：糖果街機風 HUD，SVG 圖示、3D 角色頭像（即時渲染），桌機／手機直式／手機橫式各有專屬排版
- **角色**：8 種 Q 版動物（貓、狗、兔、熊、熊貓、狐狸、青蛙、企鵝），可選毛色、衣服、配件
- **1F**：保齡球館（4 條球道，清瓶機、排瓶、回球軌動畫，計分螢幕），復古機台、彈珠台、推幣機、夾娃娃、賽車機、空氣曲棍球、雙人跳舞機，大廳有服務台和獎品牆、點心吧、影音區、搖搖馬、拍貼機
- **2F**：電玩區、投籃機、四子棋桌、空氣曲棍球、DJ 台和 LED 舞池
- **小遊戲**：貪食蛇、疊疊樂、打地鼠、打磚塊、夾娃娃、推幣機、投籃機、極速賽車、空氣曲棍球、跳舞機、四子棋
- **雙人對戰**：曲棍球、四子棋、投籃、賽車、跳舞機，一人站一邊按 E；也能和電腦玩
- **組隊**：點左上角自己的名字 →「邀請組隊」；有隊伍時在球道按 E 可以全隊輪流打
- **語音**：WebRTC 真語音（右下角麥克風按鈕），說話的人頭像和角色都有綠色光環；左上角名單裡可以看網路和語音延遲
- **一起看 YouTube**：右上角電視按鈕，貼上連結，所有人同步播放

## 連線方式（自動切換）

| 開在哪裡 | 多人 | 語音 | YouTube |
| --- | --- | --- | --- |
| 正式網站（例如 Vercel） | Supabase Realtime | WebRTC 真語音 | ✅ |
| claude.ai 預覽頁面 | 預覽頁面內建房間 | 語音轉文字 | ❌（預覽頁面不能嵌入影片） |
| 網址加 `?local` | 同一個瀏覽器的分頁互連（測試用） | WebRTC | ✅ |

## 設定

`index.html` 開頭的 config：

| 名稱 | 說明 |
| --- | --- |
| `SB_URL` / `SB_KEY` | Supabase 專案網址與 anon 公開金鑰（只用 Realtime，不讀寫資料庫） |
| `ROOM` | 頻道名稱，改掉就是另一個獨立的遊戲場 |
| `YT_API_KEY` | 選填。填入 YouTube Data API v3 金鑰後可以直接在遊戲裡搜尋影片 |

## 限制

- Supabase 免費方案：同時最多 200 人連線、每秒 100 則即時訊息。遊戲會依人數自動降低同步頻率，對戰時盡量用點對點連線，同一個遊戲場建議 8 人以內。
- 語音和對戰的點對點連線只用 STUN，沒有 TURN 伺服器，少數公司或電信網路可能連不上；對戰會自動改走 Supabase（比較慢），語音則無法使用。
