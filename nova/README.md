# NOVA 控制基地

實用的桌面小幫手，Windows 和 Mac 都能用。

## 功能

- **常用捷徑**：把程式、檔案、資料夾、網址加進來，點一下就打開
- **待辦清單**：新增、打勾、刪除，資料存在自己電腦
- **電腦狀態**：CPU、記憶體、磁碟即時顯示，有狀況時用白話提醒
- **整理下載資料夾**：依類型分到「圖片」「文件」「影片」等子資料夾，先列清單讓你確認，不會覆蓋同名檔案，還可以復原

## 怎麼跑

需要先安裝 [Node.js](https://nodejs.org)（LTS 版）。

```bash
cd nova
npm install
npm start        # 開啟 NOVA
npm test         # 跑測試
npm run dist     # 打包成安裝檔（Windows 出 .exe，Mac 出 .dmg）
```

資料存在系統的使用者資料夾（`nova-data.json`）。

## 架構

| 檔案 | 用途 |
|---|---|
| `main.js` | Electron 主程式：視窗、存檔、開檔、整理資料夾 |
| `preload.js` | 安全地把功能開放給畫面使用 |
| `lib/organizer.js` | 下載資料夾整理邏輯（計畫、搬移、復原） |
| `lib/stats.js` | 電腦狀態與白話說明 |
| `src/` | 畫面（HTML、CSS、JS） |
