# 🎳 線上保齡球

用瀏覽器就能玩的多人保齡球。輸入同一個房號就能一起玩，最多 6 人。

## 怎麼跑

```bash
cd bowling
npm install
npm start        # http://localhost:3000
npm test         # 計分和物理的測試
```

開兩個瀏覽器分頁，輸入同一個房號，就能自己測多人連線。

## 玩法

輪到你的時候，點擊畫面（或按空白鍵）三次：

1. **位置**：左右移動滑鼠（或用方向鍵）選擇站位
2. **方向**：瞄準線會左右擺動，按下去鎖定
3. **力道**：右邊的力道條會上下跑，按下去就出手

旋轉可以用畫面上的 ⟲ ⟳ 按鈕，或 A / D 鍵調整，球會在接近球瓶時拐彎（勾球）。

計分照正式規則：10 格，全倒（X）和補中（/）有獎勵分，第 10 格可以多投。

## 架構

| 檔案 | 用途 |
|---|---|
| `server.js` | Express + Socket.IO，管理房間、輪流、計分 |
| `shared/physics.js` | 球和球瓶的碰撞物理，伺服器和瀏覽器共用 |
| `shared/scoring.js` | 計分規則，伺服器和瀏覽器共用 |
| `public/` | 前端畫面（Canvas） |

**伺服器說了算**：玩家只送出投球參數，倒幾支瓶是由伺服器模擬出來的，所以改前端也作弊不了。瀏覽器用同一份物理程式播放動畫。
